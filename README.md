# Power BI Learning Lab

Hands-on Power BI examples, sample datasets, and practical techniques from my LinkedIn learning series. Each post has its own project folder with the files and instructions needed to explore the topic.

## Topics

The planned scope includes Power BI Data Modeling, Semantic Models and Relationships, DAX, Power Query, Data Visualization, Reporting and Business Intelligence, and Power BI Development Best Practices. The index below lists the projects published so far.

## Getting started

1. Browse the project index and open a post folder.
2. Download the available Power BI project and dataset using the file links in that project's README. On a GitHub file page, use **Download raw file**, or download the whole repository through **Code > Download ZIP**.
3. Open the PBIX in Power BI Desktop, which is required to use these projects.
4. Follow the project-specific instructions. Local data-source paths may need updating before a refresh.

New posts will use numbered, descriptive folders under `posts/`. Each project will be added to the index when published.
